# FitnessBase — Fitness & Gym Website

A fully responsive fitness and gym website featuring workout programs, nutrition guides, progress tracking, and coach profiles designed for health-conscious users.

🌐 **Live Site:** https://fitnesbase.netlify.app/

## Features
- Workout programs & training plans
- Nutrition guides
- Progress tracking section
- Coach profiles
- Responsive design for all devices
- Modern UI with smooth animations
